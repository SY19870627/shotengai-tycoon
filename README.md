# 台灣老街物語 Shotengai Tycoon

側視橫向捲動的台灣老街經營遊戲。你是老街管理會長：把店面租給個性鮮明的租客，處理他們之間的競爭與交情，辦廟會、發消費券、請網紅、做吉祥物，讓一條條老街重新熱鬧起來。

使用 **Phaser 3 + TypeScript + Vite**。所有美術都用程式即時繪製，沒有任何圖檔。

## 線上試玩

推到 `main` 後會自動部署到 GitHub Pages：<https://sy19870627.github.io/shotengai-tycoon/>。手機建議橫拿，用手指拖曳就能移動街道。

測試時可以在網址後面加上 `?unlock=all`，直接解鎖所有能玩的老街。

第一次使用要到 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

## 快速開始

```bash
npm install
npm run dev               # 開發模式，打開 http://localhost:5173
npm run build             # 型別檢查 + 打包到 dist/
npm test                  # 遊戲邏輯單元測試
npm run sim shenkeng 7    # 數值平衡模擬（老街 id、亂數種子）
```

## 劇情模式

| 順序 | 老街 | 難度 | 狀態 | 特色 |
|---|---|---|---|---|
| 1 | 深坑老街 | ★ | 可玩 | 離台北近、週末人潮穩。紅磚拱廊、老茄苳樹、集順廟、福德宮、永安居。人人都想賣臭豆腐 |
| 2 | 九份老街 | ★★ | 可玩 | 遊客爆量、租金高、街窄易客滿、霧雨多。豎崎路石階、昇平戲院、礦坑台車、觀景台 |
| 3 | 關子嶺老街 | ★★★ | 可玩 | 泥漿溫泉不夠分、開井會被里民抗議。好漢坡、寶泉橋露頭、水火同源、火王爺廟。妖怪祭和第 18 天的大地震 |
| 4 | 東原老街 | ★★★★★ | 可玩 | 空屋、離鄉、遊客很少。用「回憶點數」說服屋主、讓老店重新開張。老榕樹樹屋、街角小診所、戲院原址・龍眼窯 |

每條老街都有過關目標。全部達成後，隔天早上會演出結局劇情，並解鎖下一條老街。

## 玩法

- **招租**：點空店面打開「招租佈告欄」，跟應徵者面試。
  - 面試時可以看到對方的個性、經營能力和店種資料，再決定開「優惠／標準／高價」哪一種租金。
  - 開價太高，對方會拒絕。
- **收入**：每天收租金，另外抽租客營收的 10%。支出包括街道維護費、整修店面、辦活動。
- **租客**：每位租客都有滿意度。
  - 生意差、租金高、旁邊有死對頭，滿意度都會下降。降太多會來談退租，甚至直接搬走。
  - 會長可以補助裝修、送禮關心、調整租金，或是解約。
- **關係**：相鄰的租客會隨時間變成好麻吉或死對頭。
  - 好麻吉會互相介紹客人。
  - 死對頭會削價競爭。
  - 同一種店擠在一起會互搶客人。
  - 右側的「租客關係」可以看到關係圖。
- **活動**：

  | 活動 | 效果 |
  |---|---|
  | 老街消費券 | 100 元抵 120 元 |
  | 廟會遶境 | 陣頭和神轎會真的走過整條街 |
  | 吉祥物 | 永久在街上散步、跟遊客拍照 |
  | 散佈老街傳說 | 說書人坐在地標前講古，太誇張的傳說可能被拆穿 |
  | 請網紅 | 三位網紅效果不同，大嘴巴 Kevin 遇到客滿會當場吐槽 |

- **劇情**：早上、中午、傍晚都可能發生事件。
  - 角色會走到街上，用對話泡泡和表情演出，關鍵時刻讓你做選擇。
  - 例如：臭豆腐戰爭、芋圓與魚丸的三十年恩怨、茶樓被誤認成動畫場景、陶笛少年的石階演奏會。
- **日常**：沒有劇情的時候，租客也會自己走出店門閒聊、鬥嘴、放閃，心情不好的店頭上會飄烏雲。

### 九份限定的挑戰

- **天氣預報**：上方會顯示明日預報，壞天氣前一天就看得到，可以先準備。
- **濃霧**：路人變少，遊客會在石階上跌倒。沒有救護站的話，跌倒的人會扣聲望；有救護站，救護員會從服務中心跑出來處理，還會被稱讚。
- **神隱日**：濃霧日有機會變成神隱日，遊客走著走著就消失，營收流失、聲望大跌。
  - 前一晚或當天早上，礦工耆老會來警告，可以花錢請廟公辦「祈神儀式」抵銷。
  - 沒辦的話，隔天消失的遊客會在觀景台出現，一臉茫然、手上多了神秘伴手禮，「神隱傳說」反而在網路上爆紅。
- **遊客服務中心**（佔一個店面、不收租金）：可以安裝救護站、多語服務台、霧天導覽隊、尋人廣播站，每項服務都需要人力。
  - 員工要付日薪，人手不足時所有服務效果都打折，建築上會亮「人手不足」。
  - 升級建築可以安裝更多服務、雇更多人。
- **交通**：九份的人潮會被交通容量卡住，想來的人塞在山下（畫面左下角會出現排隊人龍）。
  - 小巴士 → 大巴士 → 雙層巴士，搭配加開班次、直達專車，提高容量。
  - 街口會有公車實際到站放人，換車型看得到。
- **日本、韓國旅客**：各有偏好，消費比較大方，泡泡會冒日文、韓文。沒有多語服務時進店率較低，偶爾會一臉困惑。
  - 相關事件：日本旅行團、韓國綜藝節目出外景、「九份其實不是動畫原型」的朝聖梗。
- **觀景台**：背後的山城房子會讓開，看得到太平洋、基隆山和基隆嶼，景色跟著時間變：白天的漁船、黃昏落日和海面金光、晚上的漁火和海岸燈火。路過的遊客會停下來看海，有人靠著欄杆發呆、有人自拍、有人坐長凳休息，還有人投幣用望遠鏡（$10 進管理會口袋）。
  - 黃昏最熱鬧，大家擠在欄杆前看夕陽；晚上看漁火和夜景；濃霧天望遠鏡什麼都看不到，客人會喊「退錢啦！」（錢還是照收）。
- **民宿（住一晚）**：九份可以招租民宿，三位老闆各有個性（山嵐民宿、霧宿 Fog Inn、阿嬤的厝）。
  - 傍晚旅客拖著行李箱「喀啦喀啦」走進民宿，窗戶一格格亮起，客滿會掛「今晚客滿」。
  - 隔天早上住客退房，直接在街上逛，不用擠公車，所以不佔交通容量。退房時會留星等評價，評價會影響聲望。
  - 民宿怕吵：隔壁開到半夜的店會讓住客睡不好、評價變差，擺位要取捨。
  - 九份營業到凌晨 1 點。23 點後一般遊客陸續散去，剩下睡不著的夜貓子：穿睡衣夢遊的、半夜拍夜景的、找宵夜的、看星星的。
  - 深夜事件：宵夜車進駐、神隱日前一晚的半夜敲門聲、清晨雲海日出、鄰居噪音客訴。

### 關子嶺限定的挑戰

- **泉水不夠分**：寶泉橋露頭的泉量有限。湯屋、溫泉旅館、泥漿美容、溫泉蛋都要用泉水，上方資訊列會顯示「♨ 泉量 供應／需求」。
  - 泉水不夠時，溫泉變溫：溫泉類店家吸引力下降、旅館評價變差、租客不開心。
  - 點露頭可以開新泉井（泉量 +3），但每口井都會讓**民怨**上升，三天內連續開挖、震後開挖更多。
- **民怨與抗議**：民怨分三個階段。
  - 30 連署：里民代表拿連署書來。
  - 55 布條：街上掛起「還我溫泉」，記者來採訪，聲望每天下降。
  - 80 靜坐：每天有溫泉類的店被抗議的人坐滿門口，**暫停營業**一整天，全街人潮也會減少。
  - 降民怨的方法：空店面改建**共同浴場**（不收租金，給里民免費泡）、在廟口辦**說明會**、**封井**。
- **水火同源**：點它可以決定怎麼經營。
  - 保育：只供參觀，聲望每天上升，廟公很開心。
  - 周邊擺攤（合法）：攤位擺在步道旁、不碰火，賣平安符、伴手禮、收費導覽，停下來看火的人會付錢。
  - 違規烤肉區：現實中水火同源連爆米花都不能烤，這是違法的。賺最多，但民怨上升、聲望下降，火王爺會不高興，火勢太大還可能失火；每天都可能被公所稽查，罰款、扣聲望、強制拆除。
- **好漢坡**：路過的遊客會爬上去（穿浴衣的特別想去拍照），老人家爬到一半要坐下來喘氣。下來時又累又餓，下一家吃的店消費比較高。
- **妖怪祭（溫泉美食節）**：第 7 天以後由劇情提議，之後可以從「活動」辦。
  - 前一晚大家搬食材到廟口準備；當天中午煮「天下第一鼎」，吃的店之間關係好才煮得成功。
  - 傍晚暮鼓一響，百鬼夜行開始：大型妖怪操偶遊街，遊客戴面具、鬼角、狐狸耳逛街，全街營業到凌晨 2 點。
  - **人群裡混著真的妖怪**。真妖怪的破綻會「動」：河童頭上的盤子滴水、狸貓尾巴露出來、狐狸的影子忽然不見、雪女的腳離地還會結霜。點遊客可以「識破」：猜對了妖怪付真錢、留下謝禮、好感上升；猜錯會得罪人類客人。
  - 沒被識破的妖怪付的是**樹葉錢**：隔天早上晨鐘一響，收銀機裡的錢變成樹葉。可以認賠、拿去火王爺廟燒掉，或請有創意的租客做成「妖怪葉子護身符」來賣（可能被記者踢爆）。
- **溫泉旅館的方案**：點溫泉旅館可以推出方案，能同時推幾個看旅館等級，費用由管理會出。
  - 大眾溫泉泳池：週末入住率大增、白天賣泳客門票，但最耗水，也會吵到隔壁的住宿。
  - 泥漿 SPA 套裝：和泥漿美容店合作，住客隔天頂著灰臉逛街。
  - 甕缸雞晚餐套餐：不用泉水，甕缸雞店每位住客分到一份晚餐錢。
  - 星空露天風呂：晴天晚上評價大加分，下雨天泡不了。
  - 秀子姨很傳統，泳池和星空風呂她不太喜歡。
  - 隱藏彩蛋：好好守護這座山，晴天的晚上也許會有驚喜。
- **第 18 天大地震**：前三天會有預兆（泉水變濁、火苗亂跳、老泉工水伯來警告），可以先花錢加固管線。
  - 地震時泉量大減，**開過越多井損失越大**；水火同源的火反而變大，商人會來遊說趁機開違規烤肉區。
  - 震後一週泉水會自然恢復一部分，其他要靠開新井，或是……震後的妖怪祭，以前被好好對待的河童會帶族人來報恩。
  - 過關目標包含「震後泉量恢復到震前的 80%」，所以一定會經歷地震。

### 東原限定的挑戰

設計規格見 [docs/dongyuan-spec.md](docs/dongyuan-spec.md)。

- **回憶點數**：往事、味道、人情、手藝。錢只夠付維護費，真正重要的是回憶。
- **找屋主**：空屋不能花錢整修，要帶著回憶說服住在外地的屋主。屋主各有個性和條件（不能改裝、只租給信得過的人、要幫忙澆花），有的要先發生劇情才談得動。
- **老店重新開張**：冰店、盤子碗粿、炸饅頭、打鐵舖的作法已經失傳，找回作法後才會有人來接手。
- **居民與遊客**：平日街上幾乎只有居民，消費低但每天都來，邊買邊聊會慢慢累積回憶（理髮店最愛講古）；週末單車隊、遊覽車一波一波來。
- **鄉親認同**：給居民的店越多，居民越把老街當成自己的，人變多、聊出回憶更快；只顧遊客的話，居民會說「老街變得不像我們的了」。
- **白布電影**：每天傍晚 18:00 以後點龍眼窯（戲院原址），在白布上放老膠卷，回到 1995 年的東原度過一段「回憶時光」（2016 年的時間停在當晚）。點店家進去幫忙（煮冬瓜茶、灌花生糯米腸、拉風箱、陪肉圓伯顧店……），每次過一個半小時，第一次幫忙的店找回的回憶最多；荒廢的戲院變成蛇窟，囡仔偷跑進去會被阿母拿藤條追。在過去學過的作法，回到 2016 年讓老店重開需要的回憶會變少；有些小事也會改變 2016 年（小蝴蝶效應）。
- **1960 糖廠時代**：白布電影固定 1995 → 1960 交替。1960 年的大埔街是木造店屋、遠方糖廠的煙囪冒著白煙、運甘蔗的三輪車慢慢開過。可以幫肉圓攤顧攤（顧攤的小男孩就是肉圓伯）、在雜貨店看小孩用米換糖、踩縫紉車做棉花糖、在戲院門口幫阿婆賣瓜子等散場……每三趟有一趟剛好遇到糖廠發薪日。每趟開場會放一段童年過場（找吃的、抽甘蔗、偷黑糖膏、十八重溪）。
- **每間店最多幫 3 次**：1960、1995 年每間店、戲院、老榕樹各能幫 3 次，用完就不能再點。兩個年代全部幫完後，老膠卷會損壞，再也回不去；之後每天傍晚可以花錢在龍眼窯前放一場免費的露天電影，村民晚上都會出來看。
- **老店的現實**：老店很難賺錢，常常賠錢。老店老闆不會因為賠錢就收，但會一直來找會長抱怨。
- **東原的日常**：每天都有不同的場景。週一晚上夜市；週二、週四下午香腸伯開改裝的三輪貨車來賣香腸、黑輪；週三下午鹹酥雞在國小擺攤，開攤前開車繞全村喊「禮拜三喔——來養那攤鹹酥雞——！」；週五早上早市（柳丁、龍眼、青菜）；週末遊客。每種場景第一次遇到時都有介紹。
- **老街的明天（未來計畫）**：右邊的「未來」可以花錢推動計畫，完工後老街永久改變，讓老店真的有生意：夜市早市升級、東山農產團購（龍眼乾，之後擴大到龍眼蜜、柳丁、冬瓜茶磚、手工菜刀）、土地公的活動（可重複辦）、社區廚房、返鄉青年基地、開墾山林步道、腳踏車越野賽（條件很多，辦一次就有長期效果）。
- **龍眼焙季（第 10～16 天，代表七、八月）**：家家戶戶生火焙龍眼，煙和香味籠罩老街；白天居民在騎樓下剝龍眼打零工，傍晚領了工錢才出來逛街；香味引來遊客，龍眼乾舖和團購訂單變多。未來計畫「龍眼焙季體驗」要趁焙季前辦，辦了之後焙季期間每天都有遊客專程來。
- **三年一次的全山頭繞境**：固定在第 20 天。之前可以花錢準備辦桌、燈籠、大鼓舞龍隊、攤位與接駁，準備越多當天越熱鬧。老榕樹旁有一間土地公廟。
- **回憶巡禮（過關條件）**：18 個巡禮點散落在 1960、1995 年。先在回憶時光裡找到那段回憶，回到 2016 年，在同一個地方（房子要先說服屋主）付回憶點亮：浮現當年的老照片，街坊走過來說幾句當年的事，鄉親認同上升。右邊的「巡禮」可以看到所有巡禮點和提示。過關目標：點亮全部巡禮點、鄉親認同達到 100、完成 3 個未來計畫。全部達成後，傍晚會舉辦白布電影之夜（結局），最後放一段依未來計畫而不同的「十年後的東原」。

### 新增一條老街

1. 在 `src/content/` 新增一個檔案，照 `shenkeng.ts` 的格式填入以下內容：
   - 配置：店面與地標的排列
   - 租客
   - 劇情
   - 吉祥物與傳說
   - 過關目標
2. 新地標的畫法加在 `drawLandmarks.ts`，新店種加在 `core/shops.ts`。
3. 在 `content/index.ts` 把那條街從 `comingSoon` 換成真的資料。
4. 用 `npm run sim <老街id>` 調整數值。

劇本範例：

```ts
script: (b) => [

  appear(b.a),

    opt('辦比賽', { rel: [[b.a, b.b, 30]] }, [fx('confetti', b.a)], 3000),
    opt('不管了', { rep: -1 }),
  ),

```

## 存檔

每天打烊時自動存到瀏覽器的 localStorage，每條老街分開存。開發模式下可以在 console 用 `__shotengai.store.state` 查看狀態。

# 晴空商店街 Shotengai Tycoon

側視橫向捲動的商店街經營模擬遊戲。你是一條冷清老商店街的新會長，招募店家進駐、安排鄰居組合、升級店面，讓路人變多、聲望變高，目標是拿下「年度商店街大賞」。

使用 **Phaser 3 + TypeScript + Vite**，所有美術都用程式即時繪製，不需要任何圖檔。

## 快速開始

```bash
npm install
npm run dev      # 開發模式，打開 http://localhost:5173
npm run build    # 型別檢查 + 打包到 dist/
npm test         # 遊戲邏輯單元測試
npm run sim      # 數值平衡模擬（跑 25 天，可加種子：npm run sim 42）
```

## 線上試玩

推到 `main` 後會自動部署到 GitHub Pages：<https://sy19870627.github.io/shotengai-tycoon/>（手機也能玩，用手指拖曳移動街道）。

第一次使用要到 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。

## 玩法

| 操作 | 方式 |
|---|---|
| 開店／管理店家 | 點擊店面 |
| 移動街道 | 拖曳畫面、滑鼠滾輪、← → 或 A D |
| 暫停／速度 | 空白鍵、1 / 2 / 3，或右上角按鈕 |
| 取消選取 | Esc |

- **一天**從 07:00 營業到 23:00（1 倍速約 2 分鐘），打烊後結算毛利、扣店面開銷、調整聲望。
- **路人**會從街頭牌坊或店與店之間的巷子出現，逛一段街，經過店門口時依吸引力決定要不要進去，最多進 2 家店。
- **店滿**時客人會被擋在門外，降低聲望 —— 該升級了。
- **聲望**越高路人越多，也會解鎖更高階的店種。
- **負債**超過 $10,000 就破產。

### 店種

| 店 | 類別 | 解鎖聲望 | 特色 |
|---|---|---|---|
| 雜貨店 | 民生 | 0 | 便宜、穩定 |
| 麵包店 | 餐飲 | 0 | 早上生意好 |
| 拉麵店 | 餐飲 | 10 | 客單價高，午晚餐尖峰 |
| 咖啡廳 | 休閒 | 15 | 坐得久，喜歡書店／麵包店當鄰居 |
| 書店 | 零售 | 20 | 來客少但大幅提升聲望 |
| 花店 | 零售 | 25 | 讓兩側鄰居吸引力 +8% |
| 服飾店 | 零售 | 35 | 進店率低、客單價最高 |
| 居酒屋 | 餐飲 | 45 | 17:00 才開，夜晚主場 |

### 鄰居加成

相鄰的店會互相影響吸引力，例如：咖啡廳＋書店 ×1.3、咖啡廳＋麵包店 ×1.25、服飾店＋花店 ×1.2；同一種店相鄰則會互搶客人（×0.85）。完整表格在 `src/core/shops.ts` 的 `SYNERGY`。

### 每日事件

下雨天、夏日祭典、美食節目採訪、發薪日、熱浪 —— 會改變人潮與特定店種的吸引力。

## 專案結構

```
src/
├── core/            # 純遊戲邏輯，不依賴 Phaser（可單獨測試）
│   ├── shops.ts     # 店種資料、升級費用、鄰居加成表
│   ├── events.ts    # 每日事件
│   ├── game.ts      # 遊戲狀態、建造／升級／拆除、客流、結算、存檔
│   └── sim.ts       # 路人路線與整天的數值模擬
├── scenes/
│   ├── BootScene.ts   # 用程式產生路人、燈籠等貼圖
│   ├── StreetScene.ts # 街景、路人、日夜與天氣、攝影機
│   ├── drawShop.ts    # 各店家立面繪製
│   └── UIScene.ts     # 資訊列、建造／管理面板、結算視窗
├── store.ts         # 場景共用狀態與事件匯流排、localStorage 存檔
├── theme.ts         # 尺寸、配色、天空顏色等
└── main.ts
tests/               # Vitest 單元測試
scripts/balance.ts   # 平衡模擬腳本
```

畫面上的路人與 `sim.ts` 的數值模擬共用同一套進店規則（`enterChance`、`passerbyRoute`），調整數值後可以先用 `npm run sim` 看曲線，再進遊戲確認手感。

## 存檔

每天打烊時自動存到瀏覽器的 localStorage。在結算畫面關掉網頁，下次會從下一天開始。

開發模式下可以在瀏覽器 console 用 `__shotengai.store.state` 查看或修改狀態。

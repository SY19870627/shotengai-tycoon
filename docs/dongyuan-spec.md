# 東原老街 設計規格（第四章・最終章）

> 狀態：規格草稿，等確認後再實作。
> 原則：**全部角色都是虛構的**。店種、味道、街景、小孩子的玩法來自真實的東原記憶，但不對應任何真實人物或店家。
> 調性：安靜、溫暖、有點感傷，但保留前三章的幽默。

## 0. 這一章跟前三章哪裡不一樣

| 老街 | 主要壓力 | 怎麼賺 |
|---|---|---|
| 深坑 ★ | 同種店互搶 | 錢 |
| 九份 ★★ | 人太多 | 錢 |
| 關子嶺 ★★★ | 泉水不夠分 | 錢 |
| **東原 ★★★★★** | **沒有人**：空屋、離鄉、遊客很少 | **回憶點數**（錢只夠付維護費） |

東原的核心是**時空跳躍**：2016 年的東原經營不起來，要回到 1960 年和 1995 年收集回憶，帶回 2016 年讓人、店、節慶一點一點回來。

## 1. 三個年代

| | 1960 糖廠時代 | 1995 老街的日常 | **2016 現在** |
|---|---|---|---|
| 玩法 | 小孩子視角的探索（§4） | 幫街坊做事、收集回憶（§5） | 經營老街（§6） |
| 氣氛 | 「大埔街」最熱鬧的最後幾年 | 糖廠早就收了，但老街還有生活感 | 人口外移、空屋變多，但有新住民家庭、國中體育班、留村的大學生在努力 |
| 街上 | 戲院、料理屋、旅社、布莊、雜貨、糖廠、運甘蔗的農用三輪車 | 雜貨店兩間、藥局兩間、肉圓、糖水冰鋪、碗粿、排骨酥湯、理髮店三間、饅頭、包子、打鐵舖 | 肉圓店、一間雜貨店、一間理髮店、空屋、樹屋、龍眼窯 |
| 回憶類型 | **往事**（糖廠、戲院、童年冒險） | **味道**、**人情**、**手藝** | 使用回憶 |

故事停在 2016 年：這一年東原真的有大學生團隊來辦生活節、做空間營造，是「有人想讓它重新活過來」的時間點。

### 參考的真實背景（只當作背景，不寫真實人名）
- 東原舊稱「大埔街」，因日治時期的前大埔糖廠（當地稱黑糖會社）而熱鬧，曾有戲院、餐廳、酒家、旅社、服飾店與雜貨店；糖廠走入歷史後人潮散去。
- 東山區人口：1971 年約 3.3 萬人，現在約 2 萬人。
- 東山龍眼乾焙灶有約 200 年歷史。
- 2013 年起有大學生團隊進入東山，把樹屋、廢棄龍眼窯活化成藝術基地；計畫結束後有學生選擇留下。2016 年東原辦了「原山生活節」。
- 東原國中：學生多為新住民子女與隔代教養家庭；設有體育班（舉重最強，校友曾參加東京奧運）與傳統藝術團隊（大鼓、舞龍、舞獅）。

## 2. 穿越方式：白布電影

- 2016 年的「戲院原址」現在是龍眼窯。每天傍晚以後，可以在窯前搭一塊白布，放映一卷「老膠卷」。
- 看著畫面，會長就回到那個年代，度過一段「回憶時光」。
- **規則**：
  - 每個 2016 年的晚上只能穿越一次，選 1960 或 1995。
  - 穿越時 2016 年的時間停在當晚，回來後接著打烊結算。
  - 一次回憶時光大約是遊戲裡的半天（真實時間約 1 分鐘），時間到畫面就淡出，回到 2016 年。
- **改變過去的程度：小蝴蝶效應**。幫 1960 年、1995 年的人一個小忙，2016 年就多一段回憶，或多一個願意回來的人。但糖廠還是會收、戲院還是會荒廢、年輕人還是會離開。改變不了大局，但守得住一些東西。

## 3. 戲院原址：同一塊地，三個樣子（招牌地標）

| 年代 | 樣子 | 演出 |
|---|---|---|
| 1960 | 東原戲院 | 傍晚散場人潮湧出，門口有零嘴攤；看板畫著虛構的電影 |
| 1995 | 荒廢的戲院，變成蛇窩 | 小孩子互相打賭誰敢進去；大人一直喊「裡面有蛇！」；可以進去探險（§5） |
| 2016 | 烘焙龍眼的窯 | 冒著龍眼的煙和香味；也是穿越入口（白布電影） |

隔壁是一間虛構的「街角小診所」，只當作街景和地標。

## 4. 1960：小孩子的探索

會長在 1960 年是「跟著街上小孩一起玩」的視角。那個年代連白米都很珍貴，小孩子到處找吃的。每次回憶時光可以做幾件事，每件事給「往事」回憶點數。

| 玩法 | 內容 | 風險／趣味 |
|---|---|---|
| **找吃的** | 在街上、田邊找龍眼、芭樂、番石榴；幫大人跑腿換一口飯 | 輕鬆，點數少 |
| **抽甘蔗** | 運甘蔗的農用三輪車很慢，在轉角減速時從後面抽一根。時機小遊戲：車速最慢那一下點下去 | **有危險**：太早或太晚會跌倒、被司機罵。劇情會讓大人認真告誡一次「這很危險」，不鼓勵 |
| **糖廠偷黑糖膏** | 拿鋼杯溜進糖廠，趁警衛不注意舀黑糖膏。躲藏小遊戲：警衛巡邏時不能動 | 被抓到會被拎著耳朵送回家，點數歸零 |
| **溪邊玩水** | 到十八重溪抓蝦、摸蛤仔、打水漂 | 下雨天不能去（水會漲） |
| **縫紉車棉花糖** | 一位愛改裝東西的阿伯，把腳踏縫紉車改成棉花糖機。幫他踩踏板，小孩圍成一圈 | 踩太快棉花糖會飛走 |
| **戲院散場** | 在門口幫忙賣零嘴，聽大人聊剛看完的電影 | 只有傍晚 |
| **糖廠發薪日** | 每隔幾次回憶時光，遇到發薪日，整條街最熱鬧 | 點數加倍 |

1960 年的店不能經營，都是歷史上本來就有的：戲院、料理屋、旅社、布莊、雜貨店、糖廠。

## 5. 1995：幫街坊做事

1995 年的老街還很有生活感。會長在店裡幫忙，換到不同類型的回憶點數：

| 店 | 幫忙做什麼 | 換到的回憶 |
|---|---|---|
| 糖水冰鋪 | 刨冰、熬糖水 | 味道：糖水的作法 |
| 碗粿店（用盤子做） | 問「為什麼用盤子？」；幫忙灌花生糯米腸 | 味道：盤子碗粿、花生糯米腸 |
| 肉圓店（全年無休） | 颱風天陪老闆守店 | 人情：「客人在等」的堅持 |
| 饅頭店 | 炸饅頭 | 味道：炸饅頭 |
| 包子店 | 包包子，跟饅頭店互相較勁 | 味道 |
| 排骨酥湯 | 端湯 | 味道 |
| 藥局（兩間） | 幫忙包藥、聽街坊聊心事 | 人情 |
| 雜貨店（兩間） | 顧店、送貨 | 人情 |
| 理髮店（三間） | 掃頭髮、聽八卦（三間的版本都不一樣） | 人情 |
| 打鐵舖 | 拉風箱、看師傅打農具 | 手藝：打鐵 |
| **戲院蛇窩探險** | 跟小孩打賭進去，找到戲院的老海報、老膠卷 | 往事（很多）；被蛇嚇到會跑出來 |

1995 年的年輕老闆，到 2016 年有的還在、有的老了、有的店已經收了。

## 6. 2016：經營

### 6.1 錢與回憶點數
- **錢**：租金很低，平常遊客很少。錢只夠付維護費、整修店面。
- **回憶點數**：四種：往事、味道、人情、手藝。主要用來：

| 用途 | 需要的回憶 | 說明 |
|---|---|---|
| **說服屋主** | 人情＋往事 | 空屋的屋主大多住外地。帶回他們阿公阿嬤當年的照片、故事，他們才願意把房子租出來，甚至搬回來 |
| **重開老店** | 味道或手藝 | 例如帶回糖水作法，冰鋪才能重新開張 |
| **生活節策展** | 四種都要 | 最終目標（§8） |

### 6.2 店面怎麼開：找屋主
- 東原的店面不能付錢整修就開，要一間一間找屋主。
- 屋主是虛構角色，各有個性：
  - 台北工程師：只要條件好就租。
  - 堅持要有人顧神明廳的阿嬤：要找她信任的租客。
  - 分家吵不停的三兄弟：要先調解。
  - 在國外工作的孫女：看到 1995 年的照片才想起老家。
- 談下來的店面租金很低，但屋主會提條件，例如「不能改裝」「要幫忙澆花」。

### 6.3 客人
- **平日**：幾乎只有村裡的居民，消費很低但每天都來，主要去雜貨店、小吃、理髮店。
- **週末**：一波一波的遊客：單車隊、遊覽車、來拍老屋的攝影團。
- **取捨**：店面要顧居民（穩定但賺得少），還是拚遊客（不穩定但賺得多）？只顧遊客的話，居民會說「老街變得不像我們的了」。

### 6.4 2016 年的角色（全部虛構）
| 角色 | 定位 |
|---|---|
| 肉圓伯 | 全年無休的肉圓店，三個年代都在：1960 年是幫忙顧攤的小孩，1995 年是壯年老闆，2016 年是老街最後一盞燈 |
| 留村的大學生 | 當年跟著大學計畫來東原、計畫結束後留下來。會長的第一個夥伴，負責文史採集 |
| 新住民媽媽們 | 嫁進東原後，接手婆家或街坊的老店（雜貨店、小吃），也在龍眼焙灶、果園工作。學會 1995 年留下來的作法後，可以讓冰鋪、碗粿這些老店重新開張，是老店的「接班人」。（山區買不到越南食材，所以不開越南小吃） |
| 國中舉重隊的孩子 | 幫忙搬東西、扛神轎；生活節上表演 |
| 國中大鼓、舞龍隊 | 當作東原的廟會活動（取代前幾章的遶境） |
| 最後的理髮師傅 | 1995 年三間理髮店的其中一位，2016 年只剩他 |
| 最後的打鐵師傅 | 在 1995 年拉過風箱的話，2016 年他願意收徒弟 |
| 回鄉的屋主們 | 被會長帶回來的回憶說服，回到東原 |

## 7. 吉祥物、活動
- **吉祥物（三選一）**：龍眼仔（焙灶的龍眼）、黑糖膏（一杯會走路的黑糖）、三輪車阿伯（甘蔗三輪車）。
- **廟會**：東原國中大鼓舞龍隊踩街。
- **露天電影夜**（新活動）：在龍眼窯前放白布電影，吸引村民和遊客；片單包括一部虛構的「十二生肖」冒險片，向小時候的露天電影致敬。

## 8. 結局：東原生活節＋白布電影

- 收集夠多回憶、開滿一定數量的店、說服幾位屋主回鄉之後，可以辦「東原生活節」。
- 生活節當晚，龍眼窯前搭起白布，放映三個年代的回憶：糖廠發薪日、縫紉車棉花糖、蛇窩探險、冰鋪、舉重隊的孩子。
- 片尾回顧深坑、九份、關子嶺的角色，整個遊戲在這裡結束。

- 回憶圖鑑收集 60%

- 說服 3 位屋主回鄉

## 9. 實作規劃（技術）

- **年代狀態**：`GameState` 加上 `era: 2016 | 1995 | 1960`。同一個街道配置，三個年代換不同的店面、地標樣子、路人。
- **1960 / 1995 回憶時光**：做成一個簡化的街景模式。店面是固定的歷史店家（不能招租），點店家或地標觸發「幫忙」小互動和小遊戲，給回憶點數。
- **2016**：沿用現有經營系統，加上：用回憶說服屋主開店面（取代花錢整修）、居民和遊客兩種客人、用回憶重開老店。
- **新繪製**：三種時代的店面風格（1960 日式木造＋看板、1995 水泥透天＋鐵捲門、2016 老舊＋空屋）、戲院三態、糖廠、甘蔗三輪車、縫紉車棉花糖機、白布電影。
- **分階段**：M1 2016 街道＋經營；M2 穿越＋1995 回憶時光；M3 1960 小遊戲；M4 生活節與結局；M5 平衡、測試。

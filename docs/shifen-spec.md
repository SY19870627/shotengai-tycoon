# 十分老街 設計規格

> 狀態：已實作（M1～M4）。數值用 `npm run sim shifen <seed>` 調整過，最後的數值以程式為準（見文末「實作後的數值」）。
> 原則：**全部角色都是虛構的**。平溪線、天燈、煤礦、瀑布來自真實的十分，但不對應任何真實人物或店家。
> 調性：**爽**。人潮一直來、錢一直跳、天空越來越滿。沒有大災難，沒有餓肚子的平日。

## 0. 定位：這一關是用來爽的

| 老街 | 感覺 |
|---|---|
| 關子嶺 ★★★ | 泉水不夠、大地震，要忍 |
| 東原 ★★★★★ | 沒有人，要一點一點找回來 |
| **十分 ½** | **火車一班一班倒進一大車人，滿天天燈** |

- 東原破關後解鎖；東原以後的老街不分順序，每一關各自完整。
- 連續兩關都在虐玩家，這一關反過來：**壓力很小，回饋很大**。
- 玩家要煩惱的不是「怎麼活下去」，而是「怎麼讓數字更誇張」。

### 爽感的三個來源
1. **人潮不會斷**：火車一直來，平日也很多人。
2. **火車穿過老街的那一刻**：大家從鐵軌上跳開、擠進兩邊的店，錢一口氣噴出來（§4）。
3. **天空越來越滿**：每放一盞天燈就留在天上，一天下來天空全是燈（§5）。

## 1. 老街基本設定

```ts
id: 'shifen', name: '十分老街', region: '新北市平溪區', difficulty: 0.5,
tagline: '火車穿過老街・滿天天燈',
facade: 'railside',       // 新的店面風格：鐵道兩旁的矮房子、鐵皮雨棚、紅燈籠
backdrop: 'pingxi-valley',// 新背景：基隆河谷、綠色山、吊橋
ground: 'rail',           // 新地面：街中間是一條鐵軌
startLots: 5, startMoney: 50000, startRep: 25,
baseTraffic: 20,          // 火車之外也一直有人
weekendMult: 1.6,         // 平日也很多人，假日更多
rentMult: 1.3,
closeHour: 22,            // 晚上放天燈最好看
weather: { rain: 0.2, fog: 0 },
visitors: { jp: 0.25, kr: 0.2 },    // 外國遊客最多的一條街
```

開場介紹（intro）：
> 一九二一年，平溪線為了運煤開進山裡。煤挖完了，火車卻沒有停——現在它載來的是一車一車的遊客。
> 火車就從老街正中間開過去，兩邊的店家伸手就摸得到車廂。遊客在鐵軌上寫願望、放天燈，火車一來，大家笑著跳回月台。

## 2. 街道配置

```
[十分車站] 店0 店1 店2 店3 [吊橋] 店4 店5 店6 店7 [老煤礦] 店8 店9 [十分瀑布]
          ════════════════ 鐵軌（整條街中間） ════════════════
```

共 10 個店面、4 個地標。**鐵軌從車站一路貫穿整條街**，店面在鐵軌兩旁。

| 地標 id | 名稱 | 功能 |
|---|---|---|
| `station` | 十分車站 | 火車進站，一次倒出一大波遊客 |
| `bridge` | 吊橋 | 拍照點，路人會停下來拍照 |
| `mine` | 老煤礦 | 運煤的小台車、礦工帽。可以辦「礦坑體驗」活動 |
| `falls` | 十分瀑布 | 街尾。大瀑布，遊客會一路走過來 |

> 現實中瀑布離老街有一段路。遊戲是寫意畫法，地標說明裡誠實寫「沿著步道走過去」。

- 天燈店 ↔ 雞翅包飯：放完天燈，邊走邊吃。
- 天燈店 ↔ 許願竹筒：願望寫不夠，再寫一個。
- 鐵道紀念品 ↔ 咖啡廳：等火車的時候。

## 4. 火車穿過老街（招牌時刻）

- 平溪線每 **20 分鐘**（遊戲時間）一班，假日 15 分鐘一班。每班火車倒出一大波遊客。
- 火車進站前：
  - 平交道「噹噹噹」響起，畫面邊框閃黃光。
  - 鐵軌上放天燈、拍照的人一起跳開，**擠進兩邊的店**。
- 火車穿過老街的那幾秒：
  - 兩邊店家的收入 **×2**，每一筆錢都噴出「+$」。
  - 每一間店至少進一組客人，連鎖跳錢，叫做「**火車連擊**」。畫面中間大字顯示「火車連擊 ×12！」。
- 這是每 20 分鐘就有一次的小高潮，不需要玩家操作，只要店開得夠多、夠好，連擊數就越高。
- 玩家可以做的事：
  - 點正在開過的火車：司機鳴笛、揮手，連擊 +1（每班一次）。
  - 升級「平溪線加班車」：假日班次更密。

## 5. 天燈（主角玩法）

### 5.1 放天燈
- 天燈店的客人會買一盞天燈，在鐵軌上寫願望，然後放上天。
- 每放一盞，天燈店進帳，**天燈就留在畫面上方的天空裡**，慢慢往上飄、越飄越小，但不會馬上消失。
- 一天下來，天空會從零星幾盞，變成滿天都是燈。晚上燈會亮，特別漂亮。
- 畫面右上角有「今天放了 238 盞」的計數。

### 5.2 天燈的顏色（願望）
| 顏色 | 願望 | 效果 |
|---|---|---|
| 紅 | 平安 | 基本款 |
| 黃 | 財運 | 那一刻整條街的收入小加成 |
| 粉紅 | 戀愛 | 情侶客變多 |
| 藍 | 事業、學業 | 附近店家口碑 + |
| 八色 | 什麼都要 | 升級後才有，價錢最高 |

### 5.3 點天燈
- 飄在天上的天燈可以點。點一下會跳出那盞燈上寫的願望（一行好笑或溫暖的話），還有「+$」小獎勵。
  - 「希望明年還可以跟阿嬤一起來。」
  - 「老闆，雞翅可以再大一點嗎。」
  - 「考上研究所！拜託！」
  - 日文、韓文的願望。
- 不點也沒關係，但點起來很紓壓。

### 5.4 天燈越放越大
- 天燈店可以一級一級升級：
  - 單色 → 四色 → 八色天燈。
  - 巨型天燈（一次 10 個人一起放，畫面上一盞特別大的燈）。
  - 天燈工坊（遊客自己畫天燈，停留時間變長、客單價變高）。
- 天燈店的數量和等級，決定「滿天天燈」的程度。

### 5.5 滿天天燈加成
- 天上同時飄的天燈越多，整條街的人潮越多（遠遠就看得到，大家都想來）。
- 到達門檻時，畫面跳出「**滿天天燈！**」，人潮 ×1.5 持續一段時間。

## 6. 輕量的小麻煩（不虐，只是讓手有事做）

沒有災難、不會破產。偶爾有好笑的小事件：
- **天燈卡在電線上**：點它，工作人員拿竹竿把它推下來，遊客拍手。
- **火車快來了還有人在鐵軌上自拍**：點他，站務員吹哨把他拉走（點了有小獎勵，不點火車會停一下再開，連擊少一點）。
- **下雨**：天燈飛不起來，遊客躲進店裡，吃的店反而好賺。
- **貓**：鄰近的猴硐有很多貓，偶爾有一隻貓沿著鐵軌散步，點它可以摸（只是可愛）。

## 7. 角色（全部虛構）

| 角色 | 定位 |
|---|---|
| 天燈阿公 | 做了幾十年天燈的老師傅，手很巧、很愛講天燈的由來。會長的第一個夥伴 |
| 天燈店的孫子 | 想把天燈做成網紅打卡點，跟阿公常常意見不合（吵架很好笑，不會翻臉） |
| 雞翅包飯老闆 | 動作超快，火車連擊時他一個人可以出十份 |
| 站務員 | 每次火車進站都在吹哨趕人，嘴巴碎碎念但人很好 |
| 退休的礦工 | 老煤礦的導覽員，講礦坑的故事 |
| 外國背包客 | 日本、韓國、泰國的遊客，各有各的好笑願望 |
| 平溪線的司機 | 每次經過都會鳴笛跟會長打招呼 |

## 8. 活動、吉祥物、傳說

- **吉祥物（三選一）**：小天燈（天燈店 +）、平溪線小火車（人潮 +）、礦坑小台車（伴手禮 +）。
- **廟會**：元宵天燈節（§9），平常的廟會是小型的天燈祈福。
- **新活動**：
  - 天燈彩繪大賽：遊客自己畫天燈，當天天燈數 ×2。
  - 礦坑體驗：老煤礦的小台車導覽。
  - 夜間天燈秀：晚上一次放一百盞。
- **傳說**：
  - 「天燈飛得越高，願望越快實現。」溫和可信。
  - 「放天燈本來是告訴躲在山裡的人：可以回家了。」有點感人，有點難證明。

## 9. 過關目標與結局

### 過關目標（草案）
1. 一天放出 1000 盞天燈。
2. 一次火車連擊達到 ×20。
3. 舉辦元宵天燈節。

### 結局：萬燈齊放
- 元宵天燈節的晚上，全街的人帶著天燈走到鐵軌上。
- 倒數「三、二、一」，畫面上一口氣放出上千盞天燈，把整個夜空填滿。
- 天燈阿公跟孫子一起放一盞巨型天燈，燈上寫著兩個人的願望。
- 最後一班火車鳴笛開過，車窗裡的乘客都抬頭看天空。

## 11. 實作規劃（技術）

- **鐵軌**：街道中間加一條鐵軌（新的 `ground: 'rail'`），火車從車站開過整條街。
- **火車**：新增 `train` 設定（班次間隔、每班人數）。火車進站時一次生成一群路人；火車通過時觸發「火車連擊」：每間有空位的店立刻進一組客人，收入 ×2，畫面顯示連擊數。
- **天燈**：
  - 天燈店每完成一位客人，生成一盞天燈物件，加到天空圖層（只在畫面上，有數量上限，超過就讓最舊的慢慢淡出）。
  - `GameState` 記錄今天放了幾盞、歷史最多幾盞。
  - 點天燈：顯示一句隨機願望＋小獎勵。
- **滿天天燈加成**：依天上的天燈數量，給人潮倍率。
- **小事件**：卡電線、鐵軌自拍、貓，都是可以點的小物件。
- **新繪製**：鐵道旁的店面、鐵軌、穿過老街的平溪線火車、天燈（多種顏色、巨型）、吊橋、老煤礦、瀑布、夜晚的燈光。
- **分階段**：
  - M1：街道、鐵軌、火車進站與人潮。
  - M2：火車連擊、天燈店與滿天天燈。
  - M3：點天燈、小事件、未來計畫。
  - M4：元宵天燈節、結局、平衡與測試。

## 12. 參考的真實背景（只當作背景，不寫真實人名）
- 平溪線在 1921 年通車，原本是為了運煤而建，煤礦沒落後轉型為觀光鐵道。
- 十分車站是平溪線上最大的聚落、遊客最多的車站。鐵軌從老街中間穿過，兩旁就是店家，火車從屋簷之間開進車站。
- 遊客習慣趁火車還沒來時，在鐵軌上放天燈。（現實中鐵道上放天燈有法規上的灰色地帶，遊戲裡是寫意畫法。）
- 天燈的由來有一個流傳很廣的民間說法：以前村民躲進山裡避土匪，留守的人放天燈告訴大家可以下山了，後來變成元宵節的習俗。
- 平溪天燈節每年元宵舉辦，十分老街會湧入大量人潮。
- 附近有十分瀑布、老煤礦、吊橋；鄰近的猴硐以貓聞名。

## 13. 實作後的數值（以程式為準）
- 難度：½ 顆星。
- 火車：平日 60 分鐘一班、假日 45 分鐘一班（遊戲時間一分鐘 = 實際 1/8 秒，20 分鐘一班會變成每 2.5 秒一班，太亂）；加班車再密 15 分鐘。8:30 第一班、21:00 最後一班。
- 每班火車倒出 24 + 店數 ×1.8 + 聲望 ×0.36 人（假日 ×1.4、雨天 ×0.75、再乘人潮加成）。
- 火車連擊：每間開著、有空位的店立刻進「等級」～「等級 +1」組客人，消費 ×3。
- 天燈：天燈店每位客人放 1 盞；三級天燈店有 8% 機會是巨型天燈（算 10 盞）；元宵天燈節當天 ×2。
- 滿天天燈：天上的燈每分鐘消散 2.5%，人潮加成 1 + min(0.6, 天上的燈 / 160)；80 盞以上跳「滿天天燈！」。
- 客滿對聲望的懲罰比其他老街輕很多（人本來就多）。
- 過關目標：一天放出 3000 盞天燈、火車連擊 ×30、舉辦元宵天燈節、累積營收 $8,000,000。模擬大約第 16～21 天過關。
- 劇情租客多了「天燈三姊妹」（第 5 天以後來應徵），確保有足夠的天燈店。

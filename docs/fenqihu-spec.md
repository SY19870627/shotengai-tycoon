# 奮起湖老街 設計規格（第五章）

> 狀態：規格第一版，等確認後才開始實作。
> 原則：**全部角色都是虛構的**。林鐵、便當、山城、雲霧來自真實的奮起湖，但不對應任何真實人物或店家（包括真實的便當店、飯店、糕餅店）。
> 調性：山城的慢、霧裡的溫暖；火車進站那幾分鐘很忙、很好笑。

## 0. 這一章跟前四章哪裡不一樣

| 老街 | 主要壓力 | 招牌玩法 |
|---|---|---|
| 深坑 ★ | 同種店互搶 | 廟會 |
| 九份 ★★ | 人太多（交通容量） | 觀景台、神隱 |
| 關子嶺 ★★★ | 泉水不夠分 | 妖怪祭、大地震 |
| 東原 ★★★★★ | 沒有人 | 白布電影、回憶巡禮 |
| **奮起湖 ★★★★** | **火車一天只來幾班，每班只停幾分鐘** | **月台賣便當、算準要做幾個便當** |

奮起湖是阿里山林業鐵路半路上的大站。以前火車在這裡加水、換車頭，乘客下車吃飯，便當一天賣到兩千多個。公路通車以後，大家開車直接上阿里山，奮起湖被「路過」了。
這一章教玩家的是**準備與預測**：每天早上決定要做多少便當，火車進站那幾分鐘全力衝刺。

## 1. 老街基本設定

```ts
id: 'fenqihu', name: '奮起湖老街', region: '嘉義縣竹崎鄉', difficulty: 4,
tagline: '林鐵便當・山城雲霧',
facade: 'mountain-wood',  // 新的店面風格：檜木、杉木板牆、鐵皮屋頂、遮雨棚
backdrop: 'forest-rail',  // 新背景：杉木林、山稜、雲海、林鐵的 Z 字形路線
ground: 'stone',
startLots: 4, startMoney: 40000, startRep: 15,
weekendMult: 2.4,
rentMult: 1.1,
closeHour: 20,            // 山上天黑得早，晚上只剩住下來的人
weather: { rain: 0.2, fog: 0.35 },  // 霧最多的一條街（§6）
visitors: { jp: 0.15, kr: 0.05 },   // 日本遊客喜歡林鐵
```

開場介紹（intro）：
> 一九一二年，阿里山的運材火車開到半山腰，在這裡停下來加水、換車頭。乘客下車吃一個用木片盒裝的便當，火車汽笛一響，再跑回車上。
> 後來公路開通了，遊覽車一路開上阿里山。奮起湖的月台，變得好安靜。

### 解鎖與順序
- 東原破關後解鎖。
- 東原以後的老街**不分順序**：不用接前一章的伏筆，也不用跟前一章同一個年代。每一章各自完整。

## 2. 街道配置

```
[奮起湖車站・月台] 店0 店1 店2 [老街遮棚] 店3 店4 店5 [車庫・老火車頭] 店6 店7 [杉木步道] 店8
```

共 9 個店面、4 個地標。

| 地標 id | 名稱 | 功能 |
|---|---|---|
| `station` | 奮起湖車站・月台 | **火車進站的地方**。點擊打開「便當準備」面板（§4） |
| `arcade` | 老街遮棚 | 有遮雨棚的窄老街。**下雨、起霧時遊客會躲到這裡**，旁邊的店在壞天氣反而好賺 |
| `garage` | 車庫・老火車頭 | 停著一台退役的蒸汽火車頭。過關目標、結局的舞台（§9） |
| `forest` | 杉木步道 | 街尾。清晨拍雲海的攝影客、住下來的遊客會走到這裡 |

> 現實中車庫在車站旁邊、步道在後山。遊戲是寫意畫法，地標說明裡誠實寫位置。

### 背景（新的 `forest-rail`）
- 一層一層的杉木林、山稜，遠方有雲海。
- 山腰上有一條林鐵軌道，火車進站前會在背景裡沿著 Z 字形慢慢爬上來（主要的視覺招牌）。
- 下午會從山谷湧上來一片霧，把背景整個罩住（§6）。

## 3. 店種

### 新店種
| id | 名稱 | 類別 | 特性 |
|---|---|---|---|
| `bento` | 鐵路便當 | 小吃 | **這一章的主角**。除了店裡賣，還會到月台叫賣（§4） |
| `pastry` | 老餅舖 | 伴手禮 | 糕餅、方塊酥這類帶下山的伴手禮，遊客上車前會買 |
| `aiyu` | 愛玉冰 | 小吃 | 便宜、快，天氣熱時好賣 |
| `wasabi` | 山葵・山產 | 伴手禮 | 山葵、竹筍、高山茶 |
| `hinoki` | 檜木小舖 | 文化 | 林場留下來的手藝，高單價、客人少 |

沿用：`cafe` 咖啡廳（阿里山咖啡）、`grocery` 雜貨店、`minshuku` 民宿、`souvenir` 伴手禮店。

### 互補加成（範例）
- 便當 ↔ 愛玉：吃完便當來一碗愛玉。
- 鐵道文物 ↔ 咖啡廳：鐵道迷一坐就是一下午。
- 老餅舖 ↔ 山葵・山產：一起帶下山。

## 4. 火車與便當（核心玩法）

### 4.1 火車班次
- 火車很少：
  - 平日：上山一班、下山一班。
  - 假日：上山兩班、下山兩班，另外有一班觀光列車。
- 每班火車在奮起湖**停 10 分鐘**（遊戲時間）。
- 每班火車有兩種乘客：
  - **過路客**：不下車，只在月台買東西。只有 10 分鐘，買不到就算了。
  - **下車客**：在奮起湖下車逛老街，搭下一班回去。有的會住下來。
- 另外有少量開車上來的遊客（公路客），全天零星進來。
- 畫面：
  - 右上角顯示「下一班車 11:20 進站」。
  - 進站前背景裡的小火車沿著山腰爬上來，汽笛響。
  - 停車時，月台上的便當小販沿著車窗叫賣，車窗一格一格伸出手來。
  - 開車鈴響，還沒拿到便當的手縮回去。

### 4.2 便當準備（每天早上的決定）
- 每天早上打開「便當準備」面板，決定今天要做幾個便當。
- 做太多：沒賣完的便當，打烊時要打折送給街坊，**虧材料錢**。
- 做太少：火車進站時賣光，**賣不到的客人會失望，口碑下降**。
- 預測的線索：
  - 平日或假日。
  - 天氣預報（下雨、起霧，下車客會變少）。
  - **飛鴿傳書**：奮起湖以前真的有人用鴿子訂便當。早上會有幾隻鴿子飛來，每隻帶著一張訂單（「下午那班車，三車廂，十二個」）。訂單是確定會賣掉的量。
- 可以升級的東西：
  - 增加月台叫賣的小販（一班車能賣更多個）。
  - 蓋鴿舍（未來計畫），鴿子變多，預測更準。

### 4.3 月台叫賣
- 火車停車的 10 分鐘裡，月台上的小販數量決定能賣多少個。
- 便當店越多，月台小販越多；但每間便當店都會分到一些客人。
- 月台也能賣其他東西：老餅舖、愛玉可以派人到月台賣（賣得比便當少）。

## 5. 下車客、留宿

- 下車客逛老街，搭下一班回去。平日只有一班下山車，下車客就逛得比較久。
- 錯過末班車的遊客（例如在咖啡廳坐太久）會住下來，民宿就有生意。
- 住下來的遊客：
  - 晚上吃比較好、會逛到很晚。
  - **清晨去杉木步道看雲海、日出**，早上的店（早餐、咖啡）有生意。

## 6. 霧（天氣）

- 奮起湖的下午常常起霧。遊戲裡**大約每兩天就有一天，下午兩點以後霧從山谷湧上來**。
- 起霧時：
  - 下車客提早回車站。
  - 但躲進老街遮棚的人變多，遮棚旁邊的店、咖啡廳反而好賺。
  - 畫面：整條街慢慢被白霧罩住，路燈提早亮起來。
- 下雨時：月台叫賣很辛苦，小販能賣的數量下降。

## 7. 颱風斷線（中段的大事件）

阿里山林鐵在現實中好幾次被颱風沖斷，最長斷了十五年。

- **第 16 天**颱風來，林鐵斷線。
- 斷線期間（大約 4 天）：
  - 沒有火車，只有少數開車上來的遊客。
  - 搶修工人住在奮起湖。**便當改成送給搶修工人**，不賺錢，但人情、口碑大幅上升。
  - 可以選擇只做觀光客生意（賺錢，但街坊會失望）。
- 搶通那天，第一班火車開進奮起湖，全街到月台迎接。
- 颱風前幾天會有預兆（廣播、老司機說「山的味道不對」），讓玩家有時間準備。

## 8. 角色（全部虛構）

| 角色 | 定位 |
|---|---|
| 便當店第三代 | 從城市回來接家裡的便當店，會長的第一個夥伴。不太會算要做幾個便當，常常做太多 |
| 養鴿子的阿伯 | 飛鴿傳書的最後一位。每天早上鴿子飛回來，他會念訂單給會長聽 |
| 退休的火車司機 | 開過蒸汽火車，每天到車庫擦那台老火車頭。結局的主角 |
| 老餅舖師傅 | 嘴巴很壞的老師傅，餅很好吃 |
| 愛玉阿姨 | 在月台賣愛玉幾十年，最懂火車進站那 10 分鐘 |
| 鐵道迷青年 | 從日本來的鐵道迷，住在民宿不想走，會幫忙翻譯 |
| 山葵農 | 住在更上面的山，一週下來一次賣山葵 |
| 攝影師 | 每天清晨在步道等雲海，晚上在民宿拿照片給大家看 |

## 9. 過關目標（草案）

1. 一天之內，月台賣出 300 個便當。
2. 修好車庫的老火車頭（未來計畫，需要錢、手藝，還有退休司機的故事）。
3. 颱風斷線時，把便當送到搶修工人手上（劇情）。

### 結局：老火車頭回家
- 老火車頭修好那天，退休的老司機重新爬上駕駛室。
- 蒸汽火車噴著白煙，從車庫開到月台。全街的人拿著便當在月台上等，像一百年前一樣。
- 車窗裡伸出的手，這次是要給大家便當。

## 10. 未來計畫（沿用東原的系統）

| 計畫 | 效果 |
|---|---|
| 鴿舍 | 每天早上的鴿子變多，便當預測更準 |
| 月台小販隊 | 月台叫賣的人數上限提高 |
| 觀光列車加開 | 假日多一班車 |
| 老火車頭修復 | 過關目標之一，修好後假日會有蒸汽火車表演 |
| 雲海步道整修 | 清晨的遊客變多 |
| 木片便當盒工坊 | 跟檜木小舖合作，便當售價提高 |

## 11. 吉祥物、活動、傳說

- **吉祥物（三選一）**：小火車頭（人潮 +）、便當盒（小吃 +）、雲霧仙子（起霧時加成）。
- **廟會**：山城的小廟遶境，從月台走到步道口。
- **新活動**：
  - 鐵道迷之日：日本鐵道迷包車上來。
  - 雲海攝影大賽：清晨有很多攝影客。
- **傳說**：
  - 「霧最濃的時候，月台會聽到以前蒸汽火車的汽笛。」很浪漫，有點難證明。
  - 「吃過奮起湖便當的人，以後一定會再回來。」溫和可信。

## 12. 實作規劃（技術）

- **火車**：新增 `train` 設定（平日、假日班次表；每班停車時間；過路客、下車客人數）。月台是一個特別的「賣場」，只在停車時間內有客人。
- **便當庫存**：`GameState` 記錄今天做了幾個便當；月台和便當店從庫存扣；打烊時結算剩下的。
- **飛鴿訂單**：每天早上產生幾張訂單（指定班次、數量），火車到站時自動扣掉。
- **霧**：沿用天氣系統的 fog，改成「下午才起霧」，加上遮棚的聚集效果。
- **颱風斷線**：沿用關子嶺「固定第幾天地震」的寫法（`quakeDay` → `typhoonDay`）。
- **新繪製**：山城木造店面、杉木林與雲海背景、林鐵小火車（Z 字形爬山）、月台叫賣、車窗伸出的手、車庫與蒸汽火車頭、鴿子、霧。
- **分階段**：
  - M1：街道、店種、火車班次、月台。
  - M2：便當準備、飛鴿訂單。
  - M3：霧、留宿與清晨、颱風斷線。
  - M4：劇情、結局、平衡與測試。

## 13. 參考的真實背景（只當作背景，不寫真實人名）
- 奮起湖車站建於 1912 年，是阿里山林業鐵路上重要的中繼站，蒸汽火車在這裡加水、補充燃料、換車頭，乘客在這裡休息用餐。
- 阿里山公路通車以前，一天只有幾班火車，奮起湖的便當一天最多賣到兩千多個；有一說當年用飛鴿傳書訂便當。便當用木片或竹片盒裝。
- 地名原本叫「畚箕湖」，因為山勢像畚箕，後來取諧音改成奮起湖。
- 車站旁的木造車庫，現在改成展示蒸汽老火車頭。
- 2009 年莫拉克颱風重創林鐵，之後十五年無法全線通車，2015 年杜鵑颱風又沖毀隧道，2024 年 7 月才全線復駛。

# 內灣老街 設計規格（第五章）

> 狀態：規格第一版，等確認後才開始實作。
> 原則：**全部角色都是虛構的**。產業史、火車、客家味道、街景來自真實的內灣，但不對應任何真實人物或店家（包括真實的漫畫家、粽子店）。
> 調性：熱鬧、有點吵、帶著山城的懷舊；比東原輕快，但結尾一樣溫暖。

## 0. 這一章跟前四章哪裡不一樣

| 老街 | 主要壓力 | 怎麼賺 |
|---|---|---|
| 深坑 ★ | 同種店互搶 | 錢 |
| 九份 ★★ | 人太多（交通容量） | 錢 |
| 關子嶺 ★★★ | 泉水不夠分 | 錢 |
| 東原 ★★★★★ | 沒有人 | 回憶點數 |
| **內灣 ★★★★** | **人潮一波一波：火車到站才有人，而且只走前半條街就回頭** | 錢＋**老街故事** |

東原是「沒有人」，內灣剛好相反：**假日人很多，但沒有人真的走進來**。
遊客下了火車，在車站附近買根香腸、一顆粽子，走到吊橋拍張照，就搭下一班車走了。平日則幾乎空城。
這一章教玩家的是**節奏**：配合火車班次準備、讓人潮往街尾走、讓遊客留下來過夜。

## 1. 老街基本設定

```ts

tagline: '小火車・山城・野薑花',
facade: 'hakka',          // 新的店面風格：紅磚＋木造二樓、日式雨淋板、客家花布
backdrop: 'mountain-rail',// 新背景：兩側山、溪谷、鐵道
ground: 'stone',
startLots: 4, startMoney: 40000, startRep: 15,
baseTraffic: 0,           // 遊客不是一直來，是跟著火車來（§4）
weekendMult: 2.6,         // 平日、假日落差最大的一條街
rentMult: 1.2,

weather: { rain: 0.25, fog: 0.05 },
visitors: { jp: 0.05, kr: 0 },
```

開場介紹（intro）：
> 一九五〇年代，內灣線鐵路開進山裡，運木材、運煤、運石灰。五千多個伐木工和礦工擠在這條小街上，戲院、酒館、茶室徹夜不熄，人家叫它「小上海」。
> 後來山禁伐了、礦挖空了，人一個一個下山。現在，假日的小火車又載滿了遊客——可是他們吃完一根香腸，就搭下一班車走了。

### 接上東原的伏筆
東原結局的信是「我們那裡也有一條老街，很多年沒有人走了……」。內灣其實假日很擠，所以建議把那一行改成：
> 「會長您好。我們那裡的老街，假日擠滿了人，可是好像沒有人真的走進來過……」

（只改東原結局的一行旁白，不影響東原的玩法。）

## 2. 街道配置

```
[內灣車站] 店0 店1 店2 [吊橋口] 店3 店4 店5 [老戲院] 店6 店7 店8 [廟口・礦坑步道]
```

共 9 個店面、4 個地標。**車站在街頭**，越往右邊離車站越遠。

| 地標 id | 名稱 | 功能 |
|---|---|---|
| `station` | 內灣車站 | **人潮入口**。火車進站時汽笛響，一波遊客從這裡湧出；開車前又往這裡回流（§4） |
| `bridge` | 吊橋口 | **回頭點**。很多遊客走到這裡拍完照就回車站（§6） |
| `theater` | 老戲院 | 已經關了很多年。重開是未來計畫之一（§8），也是結局的舞台 |
| `minepath` | 廟口・礦坑步道 | 街尾。廟會、老礦工講古、螢火蟲夜的出發點 |

> 現實中吊橋在老街旁的溪上，不在街的正中間。遊戲是寫意畫法，地標說明裡誠實寫「通往對岸的吊橋」。

### 背景（新的 `mountain-rail`）
- 兩側是綠色山稜，遠處有雲。
- 前景下方有溪谷，一條單線鐵道沿著山腳進站。
- 火車進站、出站時，背景裡會有一列小火車慢慢開過（主要的視覺招牌）。

## 3. 店種

### 新店種
| id | 名稱 | 類別 | 特性 |
|---|---|---|---|
| `zongzi` | 野薑花粽 | 小吃 | 拿了就走，**翻桌最快**，最適合吃火車人潮 |
| `sausage` | 烤香腸攤 | 小吃 | 跟粽子一樣快；但這種店一多，老街特色會變弱（§6.2） |
| `leicha` | 擂茶館 | 體驗 | 坐下來自己擂，**停留很久、客單價高**；火車人潮時容易滿 |
| `bantiao` | 客家粄條 | 小吃 | 中間型 |
| `caibao` | 菜包・紅粄 | 小吃 | 平日居民也會買，**平日的穩定收入** |
| `comic` | 漫畫館 | 文化 | 本身賺不多，但讓遊客願意往街尾走（§6） |
| `woodcraft` | 木雕・檜木 | 文化 | 伐木年代留下來的手藝，高單價、客人少 |

沿用：`grocery` 雜貨店、`cafe` 咖啡廳、`souvenir` 伴手禮店、`minshuku` 民宿（§5）。

### 互補加成（範例）
- 擂茶館 ↔ 菜包：擂茶配菜包。
- 漫畫館 ↔ 咖啡廳：看完漫畫坐下來。
- 野薑花粽 ↔ 伴手禮店：粽子一串一串帶回家。

## 4. 火車時刻表（核心壓力 1）

- 遊客**只跟著火車來**。每班火車進站，一次放出一波遊客（平日一波 6～10 人、假日一波 25～40 人）。
- 班次：
  - 平日：上午、中午、下午各一班（3 班）。
  - 假日：每小時一班（8～9 班）。
- 每一波遊客有「**要趕的車**」：大約一個半小時後要回車站搭下一班。時間到了，排隊中的遊客會直接放棄離開。
- **末班車**（約 18:30）開走後，當天來的遊客全部離開，街上只剩居民和住下來的人（§5）。
- 畫面：
  - 右上角顯示「下一班車 14:20 進站」。
  - 進站前會聽到平交道噹噹聲，車站冒出一群遊客；開車前大家又往左邊車站跑。
- 玩家可以影響班次：
  - 活動「觀光列車」：花錢請台鐵加開一班，當天多一波遊客。
  - 未來計畫「假日區間車加開」（§8）。

### 帶來的取捨
- **快的店**（粽子、香腸）在人潮時賺很多，但人潮之間沒事做。
- **慢的店**（擂茶）一次只能接幾組客人，人潮來時會滿，但每組客人花很多錢。
- 店面放哪裡很重要：靠車站的店一定吃得到人潮，街尾的店要靠玩家把人拉過去（§6）。

## 5. 末班車之後：留宿與夜晚（核心壓力 2）

- 末班車開走後，只有「住下來的人」還在街上。民宿是唯一能留住遊客的方法。
- 晚上的客人少，但很好賺：住民宿的遊客晚餐會吃比較好、會逛到很晚。
- **螢火蟲季**（第 12～18 天，類似東原的龍眼焙季）：
  - 晚上礦坑步道有螢火蟲，住下來的遊客 19:00 以後會往街尾走。
  - 街尾的店在螢火蟲季晚上特別好賺。
  - 畫面：街尾、山腳下有一閃一閃的小光點。
- 民宿的數量受到限制（屋主願意改成民宿的老屋不多），要權衡「白天的店」還是「晚上的民宿」。

## 6. 人潮只走前半條街（核心壓力 3）

### 6.1 走多遠
- 每一個遊客有一個「**走多遠**」的數值，決定他最遠走到哪一間店。
- 預設：大部分遊客走到吊橋口就回頭；只有一小部分走到老戲院；幾乎沒人走到廟口。
- 讓人往裡面走的方法：
  - **老街故事牆**（§7）：每點亮一格，遊客往裡面多走一點。
  - 漫畫館、木雕這類「文化」店。
  - 老戲院重開（未來計畫）。
  - 螢火蟲季的晚上（住下來的人會走到街尾）。

### 6.2 老街的味道（輕量版的特色值）
- 香腸攤、伴手禮店是「哪條老街都有的店」。開太多（超過 3 間），會出現路人抱怨「跟別的老街都一樣」，口碑每天慢慢掉。
- 客家老店、文化店、故事牆會讓口碑上升。
- 跟深坑的「同種店互搶客人」不一樣：這裡的懲罰是**整條街的口碑**，而不是單一間店。

## 7. 老街故事（收集與過關）

內灣的人不是不見了，是**故事沒有人講**。

- 街上住著幾位老人家（全部虛構）：退休的伐木工、老礦工、戲院的放映師、以前在車站賣便當的阿婆、做檜木家具的師傅。
- 跟他們聊天（點他們、或是在他們喜歡的店開張後觸發劇情），可以聽到一段一段的往事，得到「**老街故事**」。
- 一位虛構的「退休美術老師」（畫漫畫的阿伯），會把聽到的故事畫成四格漫畫，貼在街上的「**老街故事牆**」上。
- 故事牆大約 12 格，分散在整條街上（越後面的故事，貼得離車站越遠）：
  - 「小上海」的夜晚、運木材的台車、礦坑裡的便當、戲院放映到一半停電、第一班載滿遊客的火車……
- 每貼上一格：
  - 那一段牆的位置會出現一幅小漫畫（點了可以看四格內容）。
  - 遊客「走多遠」上升一點（§6.1）。
  - 有些故事會解鎖新的店、新的屋主或新的活動。

## 8. 未來計畫（沿用東原的系統）

| 計畫 | 效果 |
|---|---|
| 假日區間車加開 | 假日班次 +2 |
| 老戲院重開 | 老戲院變成客家食堂＋放老片，遊客走到老戲院的比例大幅上升 |
| 礦坑步道整修 | 街尾多一個景點，螢火蟲季以外也有人走到廟口 |
| 平日小旅行 | 跟學校、社區合作，平日也有團體來（平日多一班遊客） |
| 野薑花復育 | 溪邊種野薑花，粽子店有自己的野薑花，吸引力上升 |
| 木雕工作坊 | 木雕店可以收學徒，遊客可以動手做 |

## 9. 吉祥物、活動、傳說

- **吉祥物（三選一）**：小火車頭（人潮 +）、螢火蟲（夜晚 +）、野薑花粽（小吃 +）。
- **廟會**：客家八音踩街，從廟口一路走到車站。
- **新活動**：
  - 觀光列車（§4）。
  - 螢火蟲夜導覽（只有螢火蟲季能辦）。
- **傳說**：
  - 「深夜在礦坑步道口，聽得到礦工收工的歌聲。」很有氣氛，有點難證明。
  - 「吊橋上許願，搭火車回家會一路順。」溫和可信。

| 老礦工 | 很少說話，故事牆最後幾格是他的故事 |

| 菜包姐 | 平日也開門的小店，是老街平日的支柱 |

## 11. 過關目標（草案）

1. 老街故事牆貼滿（約 12 格）。
2. 平日一天的遊客達到某個數字（老街不是只有假日）。
3. 完成 3 個未來計畫。

### 結局：「老街號」
- 故事牆貼滿後，鐵路局答應開一班特別列車「老街號」。
- 那天全街的人都到車站迎接；老礦工、伐木工、放映師坐在第一節車廂，回到他們年輕時下車的月台。
- 老戲院放映畫漫畫的阿伯做的動畫（故事牆的十二格動起來）。
- 結尾：另一條老街的伏筆（下一章）。

## 12. 實作規劃（技術）

- **火車**：新增 `train` 設定（平日、假日班次、每班人數、末班車）。取代一般的 `baseTraffic`：路人改成「火車到站時一次生成一群」，每個路人帶「要趕的車」與「走多遠」兩個數值。
- **走多遠**：路人在超過自己的距離後就轉身回車站，`enterChance` 只對還沒超過距離的店生效。
- **故事牆**：`GameState` 記錄已經貼上的故事；街景在對應位置畫出小漫畫。
- **螢火蟲季**：沿用東原龍眼焙季的「季節天數區間」寫法。
- **未來計畫**：沿用東原的 `FUTURE_PLANS` 系統，加上內灣的計畫。
- **新繪製**：客家店面風格、山城鐵道背景、小火車、車站、吊橋、老戲院、故事牆漫畫、螢火蟲光點。
- **分階段**：
  - M1：街道、店種、火車班次。
  - M2：走多遠＋故事牆。
  - M3：民宿＋螢火蟲季、未來計畫。
  - M4：劇情、結局、平衡與測試。

## 13. 參考的真實背景（只當作背景，不寫真實人名）
- 內灣線在 1951 年通到內灣，用來運送林木、煤礦、石灰、水泥等山區物產。
- 戰後伐木、礦業高峰時，聚集的工人估計超過五千人，戲院、酒館、茶室興起，被稱為「小上海」。
- 1970 年代以後森林禁伐、礦產減少，產業沒落、人口外移，留下許多 1950～60 年代的建築：車站、戲院、吊橋。
- 後來結合懷舊鐵道、客家飲食、漫畫與螢火蟲生態轉型為觀光老街；野薑花粽是代表小吃。
- 2007～2011 年內灣線曾因改建停駛一段（新竹—竹東），2011 年 11 月復駛。（目前規格沒有用到，可以當成劇情素材）
